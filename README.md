# SpellLens

A World of Warcraft: Forever addon: every spell and ability tooltip shows your real numbers
(spell power, crit, hit, haste, buffs, talents, weapon damage), and `/spelllens` opens a panel
with your stats, all your spells with step-by-step breakdowns, a gear planner, enchants and a
compare tab that shows what an item does to your spells over a fight.

## Install

1. Download **SpellLens.zip** from the [latest release](https://github.com/clrhc/SpellLens-releases/releases/latest).
2. Unpack it into `World of Warcraft\_classic_beta_\Interface\AddOns` (you get an `AddOns\SpellLens` folder).
3. Start the game (or type `/reload`) and type `/spelllens`.

## Update

When a newer version is out, SpellLens tells you when you sign in. Go to your
`AddOns\SpellLens` folder and run **Update SpellLens.bat**: it downloads the newest version and
installs it (your settings are kept). Then type `/reload` in the game.
`/sl update` in the game checks your guild for a newer version at any time.
